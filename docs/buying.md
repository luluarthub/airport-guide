# 购前检查与按场景选择

## 先确认五件事

1. 本地网络：省份、运营商、家宽或手机网络；同一服务在不同网络体验可能不同。
2. 设备：是否支持自己的系统、路由器和第三方客户端；仅官方客户端需要额外确认安装与登录。
3. 额度：月重置、全年共用、不限时流量包与不限量是四种不同条件；注意节点倍率。
4. 总成本：预付价格、手续费、流量重置费用、额外设备费用、限速与退款规则。
5. 证据日期：套餐官网核验与节点实测分开看。官网可访问不能证明线路可用。

## 场景入口

| 需求 | 查什么 | 资料入口 |
| --- | --- | --- |
| 预算有限 | 月付真实支付金额，是否超低价超售，当前问题标记 | [参考价格榜](rankings.md) |
| 日常主力 | 自己运营商晚高峰测试，丢包、速度与故障处理 | [全部机场](catalog.md) |
| 轻度备用 | 全年总量或不限时包，有效期与停机规则 | [价格榜的total分组](rankings.md) |
| 多设备 | 同时在线设备/IP限制，路由器是否计为一台 | 各机场独立详情 |
| 视频观看 | 目标地区与平台实际解锁，时段稳定性 | 实测记录，暂无数据时先试用 |
| AI工具 | 目标工具在所选地区的官方支持规则与账号环境 | 官方规则与自己的实际测试 |
| 旅行或境外 | 是否允许境外入口、是否另购国际站 | 官网工单 |
| 路由器 | 是否能获取订阅、协议/核心版本兼容性 | [客户端入口](clients.md) |

不按照线路名称自动推断质量。任何“专线”“原生”“家宽”标签都应以路由或测试证据确认。优惠券只看实际结算金额；默认榜单不使用未核验优惠码。先用小额、短周期验证自己的网络，确认退款期限与条件。
