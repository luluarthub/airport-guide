# 推荐指数的依据

概览的推荐指数有两种证据层级，标签会明确区分。

## 维护者主力与来源推荐等级

| 概览显示 | 规则 | 含义 |
| --- | --- | --- |
| ★★★★★ · 维护者主力 | 维护者明确报告长期主力使用体验，且未标watch/inactive | 本人长期使用推荐，优先展示；不是分项测速得分 |
| ★★★★☆ · 来源主推 | 在付费参考仓库当前可见主推荐名单中，且未标watch/inactive | 原作者主推；本仓库未亲测 |
| ★★★☆☆ · 来源收录 | 出现在低价参考仓库对比表中，且未标watch/inactive | 原作者收录；不代表好于免费名单 |
| ★★☆☆☆ · 待核验候选 | 仅在免费／试用或补充名单出现 | 用于查资料，当前活动待核验 |
| 1/5 · 暂缓 | 来源问题标记或已撤下的历史条目 | 先核对恢复情况，排除价格排行 |
| 0/5 · 已停用 | 有依据标为inactive | 保留历史查询，排除排行 |

以上是编辑收录等级，用星标便于识别来源；不表示实测性能、成功率、长期运营保证，也不是自动产生的性价比总分。不同来源的编辑标准可能不同。单价另看[价格排行榜](rankings.md)。维护者主力条目在概览与查询目录优先展示；有多个社区来源时，优先采用最高收录等级，但watch/inactive始终优先。

## 实测指数（有证据后使用）

当条目为active、quality有完整公开测试证据且测试不超过90天，概览改用“x.x/5 · 实测”。指数 =（稳定性×40% + 速度×25% + 解锁×15% + 客服×20%）÷20。原始分各0–100，地区、运营商、测试日和方法必须明确。

当前没有本仓库分项测速，因此不显示虚构实测分。维护者长期主力反馈单独采用五星主力标签，不写入quality分数。过期后退回来源等级，保留“来源”标签。邀请码和推广收益不参与指数计算。

## 概览套餐的选择

价格和容量必须取自同一套餐。在有有效期的套餐中，先选人民币（如果提供），然后选该币种最低折合月费的套餐；同价选较低实际支付额。若仅有不限时流量包，则选同币种最低支付额的包。显示币种、实际价格与付费周期，年付总量明确写“总量”。

这一选择只说明已录入套餐中的入门成本，不保证当前仍在售。未录入付费价格的候选显示“待核验”，流量可显示来源的历史试用额度，但不会视为免费付费套餐。
