# 客户端与入门

使用官方发布入口，核对系统、架构和协议支持。具体版本兼容性以项目文档为准。

| 平台 | 官方项目入口 |
| --- | --- |
| Windows / macOS / Linux | [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)、[FlClash](https://github.com/chen08209/FlClash)、[v2rayN](https://github.com/2dust/v2rayN) |
| Android | [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid)、[v2rayNG](https://github.com/2dust/v2rayNG)、FlClash |
| 多平台核心 | [sing-box](https://github.com/SagerNet/sing-box)、[mihomo](https://github.com/MetaCubeX/mihomo) |
| OpenWrt | [OpenClash](https://github.com/vernesong/OpenClash)、[PassWall](https://github.com/Openwrt-Passwall/openwrt-passwall) |
| iOS | 在 App Store 核对 Shadowrocket / Stash / Surge / Loon 的开发者、版本与官方文档 |

## 使用顺序

1. 先查机场是否仅支持官方客户端；如果是，按服务自己的下载说明操作。
2. 确认支持节点使用的协议，再从客户端官方 Releases 下载对应系统版本。
3. 登录自己的服务后台，使用官方使用文档导入个人订阅。
4. 更新订阅后测试少量节点，确认系统代理/路由设置与自己的使用目标一致。
5. 如订阅一次性或限时有效，遵守服务导入规则，勿机械开启自动更新。

订阅通常包含访问凭据，勿贴到公开 Issue、共享文档或不明订阅转换站。报告问题只提供脱敏错误、客户端版本、网络和日期。
