# 常见问题与排查

**官网打不开，代表跑路吗？**

不能由一次访问失败判断。可能是域名变更、DNS、访问限制、地区封锁或临时故障。查看已记录的官方镜像、公告和客服，再结合多来源记录。巡检只提供公开可达性线索。

**官网可达，节点一定可用吗？**

不一定。本仓库未接入任何用户订阅；网页 HTTP 状态不等于线路速度或可用性。

**为什么参考榜第一不一定适合我？**

参考榜按流量单价计算。需要同时看运营商、延迟、限速、倍率、预付金额、设备限制和测试日期。

**年付200GB是什么意思？**

可能是全年共200GB，也可能每月200GB。详情的 reset=total 表示整个有效期共用，monthly 表示每月重置。两者不会混用计算。

**不限时等于永远可用吗？**

不限时一般指流量包不按月到期，仍可能受账户规则、产品调整和服务停运影响。核对官网说明。

**流量用完，直接续费就重置吗？**

不同服务规则不同。可能需要点击重置、购买流量包，或等待重置日。向官方确认后再付款。

**导入失败怎么办？**

检查客户端版本、协议支持、订阅是否已失效、一次性导入次数与账号状态。勿公开订阅。确认官方文档后再联系服务客服。

**连接成功但目标应用打不开？**

先检查系统代理或路由规则，再确认目标服务官方支持地区、DNS与出口条件；切换节点后记录结果。不要单凭广告的“全解锁”字样判断。

**如何反馈？**

使用 [问题入口](https://github.com/luluarthub/airport-guide/issues/new/choose)，提供日期、运营商、地区、套餐名、脱敏截图与公开证据链接。
