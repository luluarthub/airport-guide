# 性价比排行

价格单价只是一个维度。低价格不代表节点稳定、解锁可靠或未来持续运营。

**每100GB成本 = 支付价格 × (1 + 已知手续费) ÷ 可用流量 × 节点倍率 × 100**。月重置流量乘付费月数；全年共用和不限时流量不乘。未知手续费与倍率差异另行核验。
